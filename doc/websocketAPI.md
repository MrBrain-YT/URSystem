# Websocket API 

Разработанно для прямой связи роботов и системы без постоянного создания запросов на REST API.
При работе с websocket API вы должны отправлять json строку в запросе на сервер. Что-бы затригеррить получение данных сервера нужно отправлять токен аккаунта.

Существует два типа запросов:
- с параметром `type` - запрос такого типа подразумевает либо получение либо отправку данных на сервер. Типов бывает несколько:

    - `set` - установка значения параметра `"RobotReady", "MotorsPosition", ("PositionID" == "trigger")`. Значения для этих параметров передаёться по ключу `value`

    - `command` - выполнение какой либо операции название которой передаёться по ключу `name`. Например для удаления всех точек из multipoint позиции требуеться отправить `remove-position-points`

    - остальные запросы будут расчитаны как чтение (поведение как без параметра `type`)


- без параметра `type` -  в ответ на такой запрос будет отправлена информация о роботе которому принадлежит токен. Если токен принадлежит пользователю, то отправляються данные всех роботов.

### Структура запроса

- `Получение данных`

    ```python
    {
        "token": "akjy7wefwjgv6qohg..."
    }
    ```
- `Установка значения параметра`

    ```python
    {
        "token": "akjy7wefwjgv6qohg...",
        "type": "set",
        "parameter": "trigger",
        "value": "stert_trigger"
    }
    ```

- `Запуск комманды`

    ```python
    {
        "token": "akjy7wefwjgv6qohg...",
        "type": "command",
        "name": "remove-position-point"
    }
    ```

## Варианты параметров

- `type`
    - **set**
    - **command**
    - **shutdown**
- `parameter`
    - **MotorsPosition**
    - **RobotReady**
    - **PositionID** или **trigger**
- `name`
    - **remove-position-point**
    - **remove-position-points**
    - **remove-speed-point**
    - **remove-speed-points**

# Внимание 
- При неверной отправке токена соединение будет закрыто

- При отправке комманды на изменение параметра `RobotReady` в ответ будет отправлена команда о состоянии запроса (был ли изменён параметр)

- Запрос c типом `shutdown` выключает websocket сервер, работает только от имени `SuperAdmin`
